// Firebase Storage CORS Configuration
// Follow these steps to set up CORS for your Firebase Storage bucket

1. Install the Firebase CLI if you haven't already:
   npm install -g firebase-tools

2. Log in to Firebase:
   firebase login

3. Create a cors.json file with the following content:

{
  "origin": ["*"],
  "method": ["GET", "HEAD", "PUT", "POST", "DELETE"],
  "maxAgeSeconds": 3600,
  "responseHeader": ["Content-Type", "Content-Disposition", "Content-Length"]
}

// For production, you should restrict the origins to your specific domains:
// {
//   "origin": ["https://yourdomain.com", "https://www.yourdomain.com"],
//   "method": ["GET"],
//   "maxAgeSeconds": 3600,
//   "responseHeader": ["Content-Type", "Content-Disposition", "Content-Length"]
// }

4. Install the Google Cloud SDK (if not already installed):
   - Download from: https://cloud.google.com/sdk/docs/install
   - Follow the installation instructions for your operating system
   - Run 'gcloud init' to initialize the SDK

5. Set the CORS configuration for your storage bucket:
   gsutil cors set cors.json gs://YOUR_STORAGE_BUCKET_NAME

   Replace YOUR_STORAGE_BUCKET_NAME with your actual bucket name (e.g., safehmo-demo.appspot.com)

6. Verify the CORS configuration:
   gsutil cors get gs://YOUR_STORAGE_BUCKET_NAME

Alternative Method (Using Firebase Console):
If you don't have the Google Cloud SDK installed, you can use the Firebase Console:

1. Go to the Firebase Console (https://console.firebase.google.com/)
2. Select your project
3. Go to Storage in the left sidebar
4. Click on the "Rules" tab
5. Add the following to your rules (replace existing rules if necessary):

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      allow read: if true;  // Adjust according to your security needs
      // For production, use more restrictive rules:
      // allow read: if request.auth != null;
    }
  }
}

6. Click "Publish" to apply the rules

Troubleshooting CORS Issues:
- Make sure your Storage Rules allow read access to the files
- Check that the file paths in your code match the actual paths in Firebase Storage
- Verify that the download URLs are being correctly generated
- Test with a simple fetch request in the browser console
- Check browser developer tools for CORS-related errors in the Network tab

For more information, see:
- Firebase Storage Documentation: https://firebase.google.com/docs/storage
- Google Cloud Storage CORS: https://cloud.google.com/storage/docs/configuring-cors
