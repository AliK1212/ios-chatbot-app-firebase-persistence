# Safe HMO App - Branding Guide

This guide outlines the branding and UI design specifications for the Safe HMO mobile application.

## Color Scheme

### Primary Colors
- **Primary Orange**: #FF9800
  - Used for headers, primary buttons, and navigation elements
  - Represents energy, enthusiasm, and approachability

- **White**: #FFFFFF
  - Used for backgrounds and text on dark elements
  - Creates clean, modern feel

### Secondary Colors
- **Rich Black**: #212121
  - Used for primary text and emphasis
  - Creates strong contrast and modern appearance

- **Light Gray**: #F5F5F5
  - Used for backgrounds, cards, and secondary elements
  - Creates subtle contrast with white

- **Medium Gray**: #E0E0E0
  - Used for borders and dividers
  - Creates visual separation between elements

- **Dark Gray**: #757575
  - Used for secondary text and icons
  - Provides visual hierarchy

### Accent Colors
- **Secondary Orange**: #FFA026
  - Used for highlights and interactive elements
  - Complements the primary orange

- **Success Green**: #00B67A
  - Used for success messages and positive actions
  - Indicates completion or approval

- **Error Red**: #FF5252
  - Used for error states and destructive actions
  - Indicates problems or issues

## Typography

### Font Family
- **Primary Font**: System font (San Francisco on iOS, Roboto on Android)
  - Ensures native feel and optimal performance
  - Maintains consistency with platform guidelines

### Font Sizes
- **Heading 1**: 24px, Bold
- **Heading 2**: 20px, Bold
- **Heading 3**: 18px, Medium
- **Body Text**: 16px, Regular
- **Caption**: 14px, Regular
- **Small Text**: 12px, Regular

## UI Components

### Buttons
- **Primary Button**:
  - Background: #FF9800
  - Text: White
  - Border Radius: 8px
  - Height: 48px
  - Font: 16px, Medium

- **Secondary Button**:
  - Background: White
  - Text: #FF9800
  - Border: 1px solid #FF9800
  - Border Radius: 8px
  - Height: 48px
  - Font: 16px, Medium

- **Text Button**:
  - Background: Transparent
  - Text: #FF9800
  - Height: 40px
  - Font: 16px, Medium

### Input Fields
- **Text Input**:
  - Background: White
  - Border: 1px solid #E0E0E0
  - Border Radius: 8px
  - Height: 48px
  - Padding: 12px 16px
  - Font: 16px, Regular
  - Focus Border: #FF9800

### Cards
- **Standard Card**:
  - Background: White
  - Border Radius: 12px
  - Shadow: 0px 2px 8px rgba(0, 0, 0, 0.1)
  - Padding: 16px

## Implementation Notes

### Spacing System
- **Base Unit**: 8px
- Use multiples of the base unit for consistent spacing
- Common values: 8px, 16px, 24px, 32px, 48px

### Accessibility
- Maintain contrast ratio of at least 4.5:1 for text
- Support dynamic type for iOS
- Ensure touch targets are at least 44x44 points
- Include alternative text for all images

### Animations
- Use subtle animations for transitions
- Keep animations under 300ms for optimal UX
- Respect reduced motion settings
