# Safe HMO App - Client Handover Checklist

## 1. Required Accounts Setup

### Apple Developer Account
- [ ] Create an Apple Developer Account ($99/year)
- [ ] Enroll in Apple Developer Program
- [ ] Create App Store Connect account
- [ ] Generate necessary certificates
- [ ] Provide Team ID to development team

### Google Play Developer Account 
- [ ] Create Google Play Developer Account ($25 one-time)
- [ ] Complete account verification
- [ ] Accept developer agreement
- [ ] Set up merchant account if needed
- [ ] Provide console access to development team

### Firebase Production Account
- [ ] Create new Firebase project (separate from demo)
- [ ] Enable Authentication services
  - [ ] Email/Password authentication
- [ ] Set up Firestore Database
- [ ] Configure Storage rules
- [ ] Create production API keys
- [ ] Replace demo credentials in app

## 2. App Store Requirements

### iOS App Store
- [ ] Prepare app store listing
  - [ ] App description
  - [ ] Keywords
  - [ ] Support URL
  - [ ] Marketing URL
- [ ] Create app screenshots
  - [ ] iPhone (6.5" Display)
  - [ ] iPhone (5.5" Display)
  - [ ] iPad (12.9" Display)
- [ ] Design app icon (1024x1024)
- [ ] Privacy policy URL
- [ ] Terms of service URL

### Google Play Store
- [ ] Prepare store listing
  - [ ] Full description
  - [ ] Short description
  - [ ] Feature graphic (1024x500)
  - [ ] App icon (512x512)
- [ ] Create screenshots
  - [ ] Phone screenshots
  - [ ] 7-inch tablet
  - [ ] 10-inch tablet
- [ ] Privacy policy URL
- [ ] Content rating questionnaire

## 3. API Keys and Services

### OpenAI API Key
- [ ] Create OpenAI account
- [ ] Generate production API key
- [ ] Set usage limits and monitoring
- [ ] Provide key to development team securely

## Important Notes

1. **Current Status**:
   - The app is using demo Firebase project (safehmo-demo)
   - UI uses modern orange-based color scheme (#FF9800 as primary color)
   - Basic authentication is implemented
   - PDF chat assistant is ready for integration with OpenAI

2. **Critical Steps**:
   - Test thoroughly with production credentials before launch
   - Document all account credentials securely
